# Contributing

- Crea ramas por tarea desde `main`.
- Usa commits pequenos y atomicos.
- Formato de commit: `tipo: descripcion`.
- Incluye pruebas o stubs asociados al cambio.
- No subas secretos ni archivos de entorno local.
- Abre PR con resumen corto de cambios y riesgos.
- Pide al menos una revision antes de merge.
